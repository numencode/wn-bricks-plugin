# NumenCode Bricks plugin for Winter CMS

A translatable, block-based content builder for [Winter CMS](https://wintercms.com) static pages.

Editors compose a static page from a list of **bricks** (text, heading, image, gallery, components, …): they add,
reorder, configure and delete them. Developers define brick types as **YAML fields + Twig markup** in plugins or
themes, and themes can override them. Bricks are translatable with Winter.Translate.

> **Status:** in development, not released yet.

## Requirements

- PHP 8.2 or higher
- Winter CMS 1.2
- [NumenCode.Fundamentals](https://github.com/numencode/wn-fundamentals-plugin) 2.1 or higher
- [Winter.Pages](https://github.com/wintercms/wn-pages-plugin) (static pages)
- [Winter.Translate](https://github.com/wintercms/wn-translate-plugin) (optional, for translations)
